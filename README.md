## 1.🏋️‍♂️ Fit-Log — Fitness Tracking Application

## 📝 Description

Fit-Log is a modern and responsive fitness tracking web application that helps users manage their daily exercise routines. Users can track their total workout duration and calories burned while organizing their favorite exercises and daily workout plans.

* Live Link: https://fit-dguc7z6vm-shojib2.vercel.app/

* GitHub Repository Link: https://github.com/nuruddin2971/fit-log

## 📸 Project Screenshot: 
<img width="439" height="800" alt="fit-log" src="https://github.com/user-attachments/assets/77dad05e-b6cf-46a2-9e15-ca856b3daa70" />

## ✨ Key Features

* Today's Plan: Add workouts to your daily exercise plan and monitor workout statistics.
* Saved Workouts: Save favorite exercises for quick access in a dedicated section.
* Live Navbar Badges: Display updated counts of planned and saved workouts across the application.
* Dynamic Sorting: Sort exercises by workout duration, calories burned, or rating.
* Workout Statistics: Track total workout duration and estimated calories burned.
* Global State Management: Use React Context API to share workout plan and saved workout state across components.
* Responsive UI: Enjoy a clean, dark-themed interface optimized for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

* Next.js: React framework and application rendering
* React.js: Component-based user interface
* TypeScript: Static typing and improved code reliability
* Tailwind CSS: Utility-first styling
* DaisyUI: UI components and styling utilities
* React Icons: Icons for interface elements

## 📦 Dependencies

# The project uses the following main libraries and tools:
* next — Next.js framework
* react — React UI library
* react-dom — React DOM rendering
* typescript — TypeScript language support
* tailwindcss — Utility-first CSS framework
* daisyui — Tailwind CSS component library
* react-icons — Icon library

## 🚀 Getting Started

# Follow these steps to run Fit-Log on your local machine.

# Prerequisites

# Make sure you have installed:
* Node.js — preferably an LTS version compatible with the project
* npm (included with Node.js)
* Git

1. Clone the Repository: git clone https://github.com/nuruddin2971/fit-log.git
2. Navigate to the Project Directory: cd fit-log
3. Install Dependencies: npm install
4. Start the Development Server: npm run dev
5. Open the Application
Visit the following URL in your browser: http://localhost:3000
The application should now be running locally.

2. 📋 Job Application Tracker

### Project Overview
The "Job Application Tracker" is a functional web application designed to help job seekers manage their applications. It allows users to track which jobs are available, move them to "Interview" or "Rejected" categories, and monitor their progress via a real-time dashboard.

### 🛠 Technologies Used
*   HTML5: For core application structure.
*   Tailwind CSS: For rapid, modern UI styling.
*   DaisyUI: For pre-styled components like buttons and cards.
*   Font Awesome: For intuitive iconography (trash cans, etc.).
*   JavaScript (DOM Manipulation): For handling tabs, status updates, and dynamic counting.

### Live Link: https://nuruddin2971.github.io/Assignment-4/

### ✨ Main Features
*   Live Dashboard: Real-time counters for Total, Interview, and Rejected applications.
*   Tab System: Switch between "All", "Interview", and "Rejected" views seamlessly.
*   Application Management: 
    *   Mark jobs for Interview or Rejection.
    *   Delete specific job listings from the list.
*   Empty State Handling: Displays a "No jobs available" message when the list is empty.
*   Responsive Cards: Job details organized in a clean, card-based layout for better readability.

3. 🛠️ GitHub Issues Tracker

### Project Overview
The "GitHub Issues Tracker" is a dual-page web application designed to help teams manage software bugs and tasks. It includes a secure "Login Page" with validation and a dynamic "Main Dashboard" where users can filter, search, and view detailed information about various issues.

### 🛠 Technologies Used
*   HTML5: Semantic structure for login forms and dashboard cards.
*   Tailwind CSS: Modern styling and layout management.
*   DaisyUI: Used for the Modal system, Spinners, and themed Buttons.
*   Font Awesome: Iconography for the "New Issue" button and branding.
*   JavaScript (ES6+): Handles login logic, tab switching, and dynamic content rendering.

### Live Link: https://nuruddin2971.github.io/Assignment-5/

### ✨ Main Features
*   Authentication System: A dedicated login page with default demo credentials.
*   Issue Management Dashboard:
    *   Tab Filtering: Filter issues by "All", "Open", or "Closed" status.
    *   Search Functionality: Quickly find specific issues using the search bar.
    *   Dynamic Counters: Displays the total number of issues and their status breakdown.
    *   Modal View: Clicking an issue opens a detailed modal for more information.
*   Loading State: Includes a loading spinner for a better user experience during data transitions.
*   Fully Responsive: Grid layout that adapts from mobile (1 column) to extra-large screens (4 columns).
